# 路线图（Roadmap）

## 长期目标

以**面向智能体的编程（Agent-Oriented Programming, AOP）**作为一种新的编程范式，用于组织下一代由大模型（LLM）赋能的应用的设计与实现。

## 当前重点（2026 年 1 月 - ）

### 🎙️ 语音智能体（Voice Agent）

**语音智能体**是我们高度关注的方向，AgentScope 将持续在该方向投入。

AgentScope 的目标是构建**生产级（production-ready）**的语音智能体，而不是演示性质的原型。这意味着我们的语音智能体将：

- 支持**生产级**部署，包括与前端的无缝集成
- 支持**工具调用**，不局限于语音对话
- 支持**多智能体**语音交互

#### 开发路线

我们对语音智能体的开发策略由**三个渐进里程碑**构成：

1. **TTS 模型** → 2. **多模态模型** → 3. **实时多模态模型**

---

#### 阶段 1：TTS（Text-to-Speech）模型

- **构建 TTS 模型基类基础设施**
  - 设计并实现统一的 TTS 模型基类
  - 建立用于 TTS 模型接入的标准化接口

- **横向 API 扩展**
  - 支持主流 TTS API（例如 OpenAI TTS、Google TTS、Azure TTS、ElevenLabs 等）
  - 确保不同 TTS 供应商之间的行为一致性

---

#### 阶段 2：多模态模型（非实时）

- **为 ReAct 智能体启用多模态能力**
  - 将多模态模型（例如 qwen3-omni、gpt-audio）集成到现有 ReAct 智能体框架中
  - 支持非实时模式下的音频输入/输出

- **更高级的多模态智能体能力**
  - 支持在多模态对话中进行工具调用
  - 支持具备多模态通信能力的多智能体工作流

---

#### 阶段 3：实时多模态模型

- **超越请求-响应模式**：探索流式处理、打断处理以及并发的多模态处理
- **新的编程范式**：设计专门面向实时交互的智能体编程模型
- **生产可用性**：保证生产部署所需的低延迟性能、稳定性与可扩展性

### 🛠️ 智能体技能（Agent Skill）

提供**生产级**的智能体技能集成方案。

### 🌐 生态扩展

- **A2UI（Agent-to-UI）**：实现智能体到用户界面的无缝交互
- **A2A（Agent-to-Agent）**：增强智能体与智能体之间的通信能力

### 🚀 智能体强化学习（Agentic RL）

- 支持使用 [Tinker](https://tinker-docs.thinkingmachines.ai/) 后端，在**无 GPU**设备上对智能体应用进行调优（tune）。
- 支持基于智能体应用的运行历史对其进行调优。
- 与 AgentScope Runtime 集成，以提供更好的环境抽象能力。
- 增加更多教程与示例，展示如何借助评测模块构建复杂的 judge 函数。
- 增加更多关于数据选择与数据增强的教程与示例。

### 📈 代码质量

持续改进代码质量与可维护性。

# 已完成的里程碑

### AgentScope v1.0.0 路线图

我们衷心感谢开源社区一直以来的支持，见证了 AgentScope 的成长。在整个发展过程中，我们始终坚持以**开发者为中心的透明性**作为核心原则，并将在未来继续以此指导我们的发展。

随着 AI 智能体生态的快速演进，我们认识到有必要让 AgentScope 适应新兴趋势与需求。我们很高兴宣布即将发布的 AgentScope v1.0.0：该版本标志着 AgentScope 在部署导向与二次开发方向上的重要转变，将以更强的部署能力与更实用的特性，为智能体开发者提供更全面的支持。具体而言，本次更新将包括：

- ✨ 新特性
  - 🛠️ 工具 / MCP
    - 同时支持同步/异步工具函数
    - 支持流式工具函数
    - 支持工具函数的并行执行
    - 为 MCP Server 提供更灵活的支持

  - 💾 记忆（Memory）
    - 增强现有短期记忆能力
    - 支持长期记忆

  - 🤖 智能体（Agent）
    - 提供强大的、基于 ReAct 的开箱即用智能体

- 👨‍💻 开发体验
  - 提供增强版 AgentScope Studio，用于开发、追踪（tracing）与调试的可视化组件
  - 提供内置 Copilot，用于开发/起草 AgentScope 应用

- 🔍 评测（Evaluation）
  - 提供内置基准测试与评测工具集
  - 支持结果可视化

- 🏗️ 部署（Deployment）
  - 支持异步智能体执行
  - 支持会话/状态管理
  - 提供用于工具执行的沙箱（sandbox）
